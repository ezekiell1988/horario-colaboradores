🧹 ¿Qué se limpió?

  • 🔨

    Compilaciones guardadas de Xcode (DerivedData)

    Xcode guarda automáticamente el resultado de cada compilación de iOS para abrirla más rápido la próxima vez. Con el tiempo esto puede acumular decenas de gigabytes que ya no se usan. Se borró todo de forma segura — Xcode lo regenera solo la próxima vez que compiles.

    Liberado: 25 GB
  • 📦

    Caché de paquetes de programación (npm)

    Cada vez que un proyecto de JavaScript descarga sus herramientas, npm guarda una copia local por si la necesita otra vez. Esta caché no se limpia sola y fue creciendo hasta ocupar 14 GB. Se limpió completamente — npm la va reconstruyendo solo cuando la necesite.

    Liberado: 14 GB
  • 🐳

    Caché de construcción de Docker (sesión anterior)

    Docker guarda pasos intermedios de las "recetas" de construcción de aplicaciones para no repetirlos. Ese archivo auxiliar había crecido a 24 GB. Se redujo a 3.6 GB conservando solo lo que se reutiliza activamente.

    Liberado: ~20.6 GB
  • 💬

    Caché de ChatGPT para Mac

    La app de escritorio de ChatGPT guarda imágenes, recursos y datos temporales en una carpeta que fue creciendo hasta 1.6 GB. Se borró de forma segura — la app la recrea sola al abrirla.

    Liberado: 1.6 GB

🛡️ ¿Qué se revisó pero no se tocó?

Estas carpetas se analizaron pero se decidió conservarlas porque tienen un propósito activo:

  • iOS DeviceSupport (22 GB) — Solo tiene versiones recientes de iOS 26. Son necesarias para conectar el iPhone al Mac.
  • Android SDK (8.8 GB) — Herramientas para desarrollo de apps Android. Se necesitan para compilar.
  • Paquetes .NET / NuGet (7.6 GB) — Dependencias del ecosistema .NET. Reutilizadas por proyectos activos.
  • Extensiones VS Code (4.1 GB) — Las extensiones del editor de código. Borrarlo requeriría reinstalar todo.
  • Caché JetBrains (3.3 GB) — IDEs como WebStorm/Rider los regeneran solos; candidato para próxima sesión.
  • Dispositivos del simulador iOS (3.1 GB) — Simuladores de iPhone activos en Xcode.
